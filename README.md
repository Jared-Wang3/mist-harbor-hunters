# 雾港猎团 / MISTHARBOR HUNT

《雾港猎团》是一款明亮国风版画风格的 2D 俯视角双人联机探索动作游戏。两名玩家通过 6 位房间码签下同一份猎团契约，依次穿过「晴潮雾港」「赤灯潮市」「云汐天关」三张 5120 × 2880 的独立地图，共同探索、升级、清理区域、收集关卡目标并击败首领。

项目是一份可直接在浏览器中游玩的联机游戏垂直切片。开始主页、三关地图、可碰撞地形、角色与怪物逐帧动作、技能图标均使用实际制作的栅格美术资产，不以圆形或方块代替角色，也不依赖 SVG 占位图。

## 开始主页

进入网站后会先看到游戏主视觉、玩法入口和三章航路预览。三张预览图分别对应晴潮雾港、赤灯潮市与云汐天关，帮助玩家在签约前理解完整远征长度；开始主页只加载轻量概览，不会提前解码三关大地图或首领动画。

玩家可从主页选择单人试炼或进入契约大厅建立 / 加入双人契约。浏览器会保留当前房间与猎人名号，刷新页面后可尝试重新连接尚未过期的契约。

## 游戏卖点

- **职责鲜明的双人组合**：重刃猎人负责近战破甲与保护队友，符文枪手负责远程输出、标记与控场。
- **三章连续远征**：晴潮雾港、赤灯潮市与云汐天关拥有独立视觉主题、区域名称、关卡目标和首领。
- **真正会展开的大地图**：每关由 4 × 4 高清地图块组成；镜头跟随本地玩家移动，只加载附近地图块，并配有战争迷雾、小地图和屏外队友 / 出口指示。
- **看得见的碰撞地形**：小屋、断桥、暗礁、矮墙、塔基以及关卡地标使用透明栅格图集，并与服务端权威碰撞体保持同一位置。
- **探索与成长闭环**：怪物按区域警戒和回巢；队伍共享经验，升级会提高攻击与生命；清理三个猎场取得本关目标后才会激活首领。
- **合作换关**：击败 Boss 只会解锁出口，两人仍需一同找到出口并持续互动；服务端确认后才进入下一关，玩家身份与等级成长会跨关保留。
- **真正影响战局的协作**：猎人倒地后可由同伴靠近救援；两人同时倒下时重置当前阶段，而不是直接丢失整局进度。
- **低门槛联机**：一人建立契约，另一人输入 6 位房间码即可加入，不需要注册账号。
- **单人也能预习**：单人试炼会安排 AI 同伴，适合熟悉职业、操作与关卡流程。
- **全角色逐帧动作**：两名猎人与主要怪物 / Boss 都使用 8 × 6 透明 PNG 图集，包含待机、奔跑、攻击、受伤和倒地动作。动画按进入视野或首领阶段懒加载，兼顾手机内存。

## 双人联机玩法

1. 在开始主页进入契约大厅。第一位玩家选择“建立双人契约”，取得 6 位房间码。
2. 将房间码发给同伴；第二位玩家在“输入 6 位房间码”区域选择“加入猎团”。
3. 两人到齐后进入第一关「晴潮雾港」，系统分配重刃猎人与符文枪手。
4. 清理三个猎场并互动拾取本关目标。有人倒地时，另一人需要靠近并持续互动完成救援。
5. 目标集齐后击败关卡首领，前往出口。两名玩家都在出口范围内持续互动约 1 秒，服务端才会结算本关并进入下一关；重复请求不会跳过关卡。
6. 三关顺序固定为「晴潮雾港 → 赤灯潮市 → 云汐天关」。换关时保留玩家身份、职业、等级和队伍成长，并释放上一关的地图资源。
7. 只有完成第三关「云汐天关」的合作出口后，整场远征才进入胜利结算。

线上房间由 Cloudflare SQLite Durable Object 独立管理。活跃战斗使用 30Hz 权威模拟和 WebSocket 同步；等待、结算或无人连接时会停止循环并休眠。房间支持刷新重连并会在长时间无人活动后自动过期。本版本适合好友试玩和玩法验证，不包含账号系统、公开匹配或竞技级反作弊。

## 本地启动

需要 Node.js 20 或更高版本。

```bash
cd 雾港猎团
npm install
npm run dev
```

启动后访问终端显示的地址；默认是 [http://127.0.0.1:3000](http://127.0.0.1:3000)。打开两个浏览器窗口，分别建立和加入同一房间，即可在一台电脑上快速验证联机与换关流程。

## 美术资源构建

三张地图母图、透明地形母表、两张新首领母表和完整提示词保存在 `art-source/v5/`。构建脚本需要 Python 3 与 Pillow，在项目根目录执行：

```powershell
python scripts/build-world-tiles.py
```

该命令会机械生成：

- 三关各 16 张 1280 × 720 地图块和一张 512 × 288 航路概览；
- 一张三关共用透明地形图集和第二、第三关专属图集；
- 赤灯摄政与云汐潮甲两张 1024 × 768 透明动画图集。

可以只重建某一类资产：

```powershell
python scripts/build-world-tiles.py --kind maps
python scripts/build-world-tiles.py --kind terrain
python scripts/build-world-tiles.py --kind bosses
```

也可以只重建某关地图：

```powershell
python scripts/build-world-tiles.py --kind maps --stage stage-01
```

不得逐块手工修改地图输出，否则会破坏相邻地图块的连续接缝。若默认 `python` 报告缺少 `PIL` 模块，请切换到已安装 Pillow 的 Python 环境。

## 局域网联机

服务默认只监听本机地址。需要让同一 Wi-Fi 或局域网中的朋友加入时，可将监听地址改为 `0.0.0.0`：

```powershell
$env:HOST="0.0.0.0"
$env:PORT="3000"
npm run dev
```

随后让同伴访问 `http://你的局域网 IP:3000`。主机防火墙必须允许 Node.js 或所选端口的入站连接；结束服务后，这些内存房间不会保留。

## 公网联机

项目已部署到 Cloudflare。重新发布前先安装开发依赖，然后执行：

```bash
npm install
npm run build:cloudflare
npm run deploy:cloudflare
npm run deploy:pages
```

`worker/index.mjs` 提供静态资源、房间 API、WebSocket 与 Durable Object；`pages-gateway/` 通过 Cloudflare service binding 转发到游戏 Worker，为手机提供稳定的 `pages.dev` 入口。

线上冒烟测试：

```bash
npm run test:remote -- https://mist-harbor-hunt.pages.dev
```
